# 任务发布页面说明（Part A）

> 本文件记录前端为「Part A：任务发布与任务主流程」新增的内容。
> 接口契约仍以 `code/development_doc/openapi.yaml` 为准；本文件不放宽或改变契约。

## 页面与入口

| 项目 | 值 |
| --- | --- |
| 路由 | `/tasks/new` |
| 路由名 | `task-publish` |
| 视图 | `src/views/TaskPublishView.vue` |
| 入口 | 侧边栏「发布任务」（`src/App.vue`） |
| 权限 | 需要登录；沿用 `router.beforeEach` 的登录校验 |

## 表单字段

与 `openapi.yaml` 的 `CreateTaskRequest` 一一对应：

| 字段 | 控件 | 校验 |
| --- | --- | --- |
| `title` | 单行输入 | 非空，≤ 100 |
| `description` | 多行输入 | 非空，≤ 2000 |
| `reward` | 数字输入 | 1–1000 的整数 |
| `deadline` | `datetime-local` | 必须晚于当前时间，提交时转换为 ISO 8601 UTC |
| `pickupLocation` | 单行输入 | 非空，≤ 200 |
| `deliveryLocation` | 单行输入 | 非空，≤ 200 |

校验逻辑集中在纯函数 `validateTaskDraft`（`src/domain/tasks.js`），页面与测试共用，规则与后端
`TaskCreateRequest` 注解保持一致。

## 提交与反馈

- 调用 `api.createTask(body)`，即 `POST /api/v1/tasks`；请求走统一 `client.request`，自动携带
  `credentials` 与 `X-XSRF-TOKEN`。
- 提交期间按钮禁用，避免重复发布。
- 成功：toast 提示「任务发布成功，报酬已冻结」，随后跳转任务大厅；新任务按发布时间倒序位于首屏。
- 失败：展示服务端 `{code,message}` 中的 `message`（如余额不足、字段校验失败），保留表单内容可重试；
  余额不足时额外提供「查看钱包余额」链接。没有回退为假数据，也没有把失败显示成空列表。
- 客户端校验失败时不发送请求，直接展示提示。

## 本地演示模式

`vite.demo.js` 增加了内存版 `POST /tasks`，校验规则与页面一致，仅用于 `npm run dev:demo` 下
让发布流程可走通；演示模式仍然不实现详情、接单、送达等接口。

## 已知边界

- 本阶段不包含编辑、撤回、评价页面；后端对应接口已实现，前端封装留待后续。
- 通知、投诉、管理员查询等未实现接口未在本页面出现。
