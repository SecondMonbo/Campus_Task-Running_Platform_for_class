# 软件架构图

软件架构图用来说明**系统由哪些部分组成，以及这些部分怎样交互**。这份图解展示当前选定的软件组成和规划中的业务模块，并标明目前工程骨架已经具备的基础。

完整架构图、技术栈清单和组件职责见[架构图文档](../../.github/modernize/assessment/engines/facts/architecture-diagram.md)。

## 一句话理解

用户在浏览器使用 Vue 页面；页面通过 HTTP API 请求 Spring Boot 后端；后端负责身份与权限、任务业务和账务规则，再由数据访问层读写 PostgreSQL。开发时 Vite 负责前端热更新，并把 API 请求代理到本机后端。

## 目前已搭建与待实现

| 部分 | 当前情况 |
|---|---|
| Vue 3、Vite、Vue Router 依赖 | 已安装 |
| 前端开发状态页和后端连接检查 | 已有 |
| Spring Boot、Java 21、MVC、Security | 工程骨架已创建 |
| Session、CSRF 与健康检查 | 基础配置已创建 |
| PostgreSQL、JPA、Flyway | 连接和依赖已配置；还没有业务表 |
| 注册登录、任务、钱包、取消申诉等业务 | 待开发 |
| JPA 实体、仓储与 Flyway 迁移脚本 | 待开发 |

该项目是**单体应用**，也就是后端目前是一个 Spring Boot 程序，内部按业务模块组织；不是每个模块单独部署一个服务。后端模块职责、五人分工边界另见[分工边界与任务图](./分工边界与任务图.md)。
